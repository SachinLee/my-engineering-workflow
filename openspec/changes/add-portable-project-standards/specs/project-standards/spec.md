# 项目规范要求

## 验收标准
- AC-001：一份 project-standards 正文提供明确选择步骤、common/java/spring-mybatis-plus 按需引用；普通任务不加载全部语言；其他语言遵循仓库现有约定。
- AC-002：Java 尊重实际 JDK/依赖版本，不默认 JPA；MyBatis-Plus 覆盖可信范围、局部更新与清空、字段策略、SQL 参数、逻辑删除/审计、事务并发及适当验证，避免将项目专有锁策略提升为全局要求。
- AC-003：实现与审查上下文明确传递适用规范关键条目与必要读取路径。Pi 新子代理不依赖父会话隐式继承；OpenCode 保持 fixer/oracle 路由；一次审查预算不变。
- AC-004：共享安装、Claude 链接、OMP 白名单、doctor 与契约测试支持第七个 skill；重复安装安全，模型配置保持用户所有。
- AC-005：提供短项目入口模板、规则来源与更新说明；改编 ECC 内容记录版本与许可；csgops 内部实现不进入共享正文。
- AC-006：记录实际检查和安装证据，区分安装 PASS 与运行时 UNVERIFIED；旧 ECC 规则只在备份和识别用户内容后处理，不覆盖整个用户目录。
